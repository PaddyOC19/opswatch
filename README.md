# OpsWatch

A full-stack monitoring and incident management platform.

## Project Goals

- Monitor HTTP endpoints and track their availability.
- Detect service failures and manage incidents.
- Build a React and TypeScript frontend.
- Develop a Python FastAPI backend.
- Store monitoring data in PostgreSQL.
- Implement automated testing and CI/CD.
- Deploy the application to AWS using Terraform.

## Technology Stack

- Frontend: React, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL
- DevOps: Docker, GitHub Actions, Terraform, AWS

## Status

Early development — learning and building incrementally.

## Learning Approach

This project is being developed as a practical full-stack and DevOps learning exercise, with progress, technical decisions and lessons documented throughout development.
